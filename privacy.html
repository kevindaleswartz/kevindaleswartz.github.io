Bookkeeper privacy policy

Last updated November 13, 2026.

Bookkeeper is a personal Windows program used only by its owner on their own computer.

What Bookkeeper accesses

When the user connects a Google account, Bookkeeper reads the user's email address and the user's Google Calendar calendars and events, and adds, changes or deletes events only when the user asks it to.

How the information is used and stored

Calendar information is used only to show and edit the user's own calendars inside Bookkeeper. It is kept on the user's own computer. Sign-in tokens are stored encrypted with Windows' own data protection for that user.

Sharing

Bookkeeper does not sell, share or transfer Google user data to anyone, does not use it for advertising, and does not use it to train AI models.

Bookkeeper's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The user can remove an account in Bookkeeper's Calendar tab, or revoke Bookkeeper's access at any time at myaccount.google.com/permissions.
